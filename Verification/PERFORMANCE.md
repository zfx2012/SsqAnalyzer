# 性能优化记录：2026-09-21

本轮先测量热点，再修改两处计算内部实现。正式和影子算法的版本、参数、公式、排序规则及数据格式保持不变。

## 测量条件

- 同机、同一 .NET 运行时，Release 构建，`DOTNET_TieredCompilation=0`。
- 固定种子 `731927`，510 期合成数据：450 期往年记录、60 期当年记录。年度研究使用往年尾部 60 期及当年前 30 期。
- 每项预热一次，随后 3 或 5 个样本取中位数；同一进程中依次执行各项。
- 分配数据来自 `GC.GetAllocatedBytesForCurrentThread`，表示一次操作期间累计分配的托管字节数，不是内存峰值或常驻内存，不含原生/GPU/其他线程分配。
- 本记录是固定数据的局部实验，短耗时及小幅变化可能受调度和机器负载影响，不推断为所有场景的提升。
- 性能测量命令见 [README.md](README.md)。

## 已实施的两处优化

### 蓝球周期公式

原实现对每个历史目标期、每个蓝球重复扫描历史前缀，并构造位置列表。现在一次遍历维护每个蓝球的首次位置、最后位置和出现次数，生成每个历史前缀对应的预测。

连续间隔之和等于最后位置减首次位置，所以原平均间隔可精确写为 `(last - first) / (count - 1)`。扫描号码仍按升序，只在分数严格更大时替换候选，保留同分取最小号码的行为。每个前缀只纳入它之前的数据。结果数组仅属于本次公式评估或集成历史对象，无跨请求静态缓存。

### 条件概率模型的临时表

原条件模型在每轮训练的每期样本上重新创建两张前缀/后缀表。现在在一次模型拟合内各创建一次并复用；边界零行保持不变，内部单元格每次全部覆盖。循环和浮点运算顺序保留，拟合之间不共享数组。

## 结果

| 测量项 | 优化前中位耗时 | 优化后中位耗时 | 前/后累计分配（MiB/次） |
|---|---:|---:|---:|
| 下一期完整预测 | 7.54 ms | 1.95 ms | 5.50 / 2.91 |
| 30 期滚动回测 | 219.85 ms | 60.58 ms | 162.89 / 86.96 |
| 蓝球评分 | 7.25 ms | 1.41 ms | 5.14 / 2.55 |
| 蓝球公式评估 | 5.59 ms | 0.16 ms | 2.66 / 0.06 |
| 条件分层模型拟合 | 5.52 ms | 4.87 ms | 7.99 / 2.43 |
| 30 期年度研究 | 2778.38 ms | 2648.23 ms | 1594.97 / 1261.48 |

完整预测耗时约减少 74%，30 期回测约减少 72%；条件模型拟合累计分配约减少 70%，年度研究约减少 21%。年度研究的耗时差约 5%，仅作为观察值，不据此宣称稳定加速。

其他未修改的测量项作为参考：

| 测量项 | 优化前/后耗时 | 前/后累计分配（MiB/次） |
|---|---:|---:|
| 生成 20 注组号 | 3.02 / 2.93 ms | 5.36 / 5.36 |
| 100 期矩阵增量刷新及布局 | 1.18 / 1.45 ms | 0.13 / 0.13 |
| 100 期矩阵重建及布局 | 195.50 / 189.23 ms | 47.15 / 47.15 |
| 蓝球排除可靠性评估 | 1.57 / 1.29 ms | 2.42 / 2.42 |
| 独立分层模型拟合 | 2.75 / 2.51 ms | 0.39 / 0.39 |

未修改项的耗时波动不归因于本轮优化。矩阵重建约 190 ms，明显高于同数据引用的增量刷新；这是后续交互性能优化的候选，应结合真实页面的数据引用和筛选操作进一步测量。
