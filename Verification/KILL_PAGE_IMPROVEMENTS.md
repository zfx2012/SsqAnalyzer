# 杀号规则页交互优化

2026-09-22。保持规则计算、回测引擎、仓储格式和杀号算法不变。

- 修复名称和描述列误按规则 ID 排序；启用状态按布尔值排序，准确率按数值排序，缺少有效统计的规则始终置后。同列第三次点击恢复默认顺序。序号和统一门槛不提供无意义排序。
- 刷新保留筛选、回测窗口、排序指示、选中规则和滚动位置；合并连续规则变更引发的刷新。
- 搜索 ID、名称、描述，支持球种和启用状态组合筛选；显示总量、启用量、当前结果数量；提供重置和空结果提示。
- 窗口切换立即更新准确率和窗口判定。未回测、没有有效样本和样本不足不再错误显示为达标。
- 启用状态保存失败时恢复原值；回测期间禁用门槛修改；批量回测和执行杀号的提示明确说明不受列表筛选影响。
- 明确详情按钮、双击和 Enter 入口；双击复选框或按钮不再误开详情。详情显示当前窗口、最近回测时间和对应窗口的错误样本，不跨窗口借用错误样本；代码折叠且可选中复制。
- 顶部操作和窗口选择分行，筛选和页脚支持换行，选中行文字和状态颜色保持可读，描述支持完整悬停提示。

窗口说明：原“200”按钮实际映射全部回测，没有独立的 200 次引擎窗口，因此移除重复入口。现有引擎在同一统计字段保存最近一次“100 次 / 全部”结果；本次保留数据兼容，页面和详情明确提示。全部视图仍遵循原有优先 100、再 50、再 30 的有效统计选择。

验证覆盖在 `KillPageVerification.cs`，纳入原有页面生命周期验证组；使用真实 WPF 控件和内存规则仓储，不修改用户规则文件。
